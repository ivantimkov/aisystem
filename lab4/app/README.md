# AI Code Assistant

Локальний AI-помічник для роботи з програмним кодом на основі великої мовної моделі Qwen3 1.7B та середовища Ollama.

## 1. Опис проєкту

AI Code Assistant — це вебзастосунок, який допомагає користувачам вивчати програмування та працювати з програмним кодом за допомогою локальної мовної моделі.

Застосунок використовує Python, Gradio та Ollama. Взаємодія з мовною моделлю відбувається через API, сумісний з OpenAI API.

## 2. Основні можливості

Застосунок містить три основні інструменти:

### AI-чат
- Відповіді на запитання з програмування.
- Пояснення програмних конструкцій.
- Підтримка історії діалогу.

### Аналізатор коду
- Пошук синтаксичних і логічних помилок.
- Виправлення програмного коду.
- Пояснення принципу роботи коду.
- Оптимізація програмного коду.
- Автоматична перевірка синтаксису Python за допомогою модуля `ast`.

Підтримувані мови:
- Python
- Java
- C#
- C++
- JavaScript
- SQL
- PHP

### Генератор коду
- Створення програм за текстовим описом.
- Генерація прикладів коду.
- Додавання коментарів.
- Пояснення згенерованого рішення.

## 5. Встановлення та запуск

### Крок 1. Встановлення Ollama

Завантажити Ollama можна з офіційного сайту:

https://ollama.com/download

### Крок 2. Завантаження моделі

Відкрити PowerShell та виконати:

```powershell
ollama pull qwen3:1.7b
```

### Крок 3. Встановлення бібліотек

Перейти до папки застосунку:

```powershell
cd app
```

Встановити необхідні залежності:

```powershell
pip install gradio==6.31.0 openai
```

### Крок 4. Запуск застосунку

Переконатися, що Ollama запущений, після чого виконати:

```powershell
python app.py
```

Після запуску Gradio відобразить адресу локального вебінтерфейсу в терміналі. Відкрити її у браузері.

## 6. Параметри генерації

У застосунку використовуються такі параметри:

| Параметр | Значення | Призначення |
|---|---:|---|
| Model | qwen3:1.7b | Використовувана модель |
| Temperature | 0.4 | Контроль варіативності відповідей |
| Max tokens | 1024 | Максимальна кількість токенів відповіді |
| Context length | 4096 | Розмір контексту моделі |

Параметри можна змінити у файлі `app.py`.

## 9. Особливості реалізації

Застосунок використовує локальну мовну модель, тому запити до неї обробляються на комп'ютері користувача через Ollama.

Для перевірки синтаксису Python використовується вбудований модуль `ast`, що дозволяє виявляти синтаксичні помилки без звернення до мовної моделі.

Для створення інтерфейсу використовується Gradio, який забезпечує взаємодію користувача з AI-чатом, аналізатором та генератором коду.
