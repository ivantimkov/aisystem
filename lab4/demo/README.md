# Демонстраційні скриншоти AI Code Assistant

Ця тека містить скриншоти фактичного тестування застосунку для лабораторної роботи №4.

- **01_python_syntax_error.png** — Аналізатор коду: виявлення синтаксичної помилки Python — незакрита дужка/лапка у виклику функції.
- **02_code_correction.png** — Аналізатор коду: виправлення коду. Модель повернула варіант із закритою дужкою та пояснила зміну.
- **03_code_explanation.png** — Аналізатор коду: пояснення програмного коду. У цій відповіді модель допустила арифметичну неточність; це зазначено як обмеження.
- **04_code_optimization.png** — Аналізатор коду: приклад оптимізації — скорочення обчислення середнього значення.
- **05_code_generation.png** — Генератор коду: створення програми керування списком студентів.
- **06_generated_program_run.png** — Перевірка згенерованої програми: додавання студента та перегляд списку в консолі.
- **07_empty_input_validation.png** — Перевірка порожнього запиту: застосунок показує повідомлення з проханням описати завдання.

## Примітка

Скріншоти відображають окремі етапи тестування. Під час пояснення коду модель допустила арифметичну неточність (7.75 замість 10.25); цей недолік не приховується та описаний у звіті.
